#############
Reference/API
#############

The public API of ``convolve_uv`` is the function and the warning class below, which are
imported from the package itself (``from convolve_uv import convolve_uv``). Everything else
in the package, including the ``convolve_uv._numerics`` module of numerical helpers, is
internal and may change without notice.
